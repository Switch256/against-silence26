# AEGIS-MEDLINK

**Against the Silence** · NASA International Space Apps Challenge 2026 · *Care Beyond Connectivity*

Offline-first astronaut health monitoring (AEGIS) with delay-tolerant medical communication over BPv7 (MEDLINK).

## Public demo

The frontend includes a labelled simulated-data fallback. The public showcase loads the astronaut and Earth consoles without a login, database, or backend server; live API data takes over automatically when a backend is configured. After Pages is set to **GitHub Actions**, the demo is published at https://switch256.github.io/against-silence26/demo/.

Run it locally with `cd frontend && npm install && npm run dev`.

For NASA Space Apps submission, keep all project-page text and slides in English, test every public link in a private browser window, and submit through **My Team → Project → Submit for Judging** before the local deadline.
